## 修复 scripts/download-cores.ts 的 Windows 兼容性 bug
- 问题：`bun run dev` → `download:cores` 在 Windows 上下载 mihomo 会失败。
  根因是 Windows 分支硬编码 `join('/tmp', 'mihomo.zip')`，在 Windows 上解析为不存在的 `C:\tmp`，
  `curl -o` 因父目录不存在直接报 "Failed to create file"，根本到不了后面的 `Expand-Archive`。
- 修复：改用 `os.tmpdir()` 构造临时 zip 路径（`C:\Users\...\AppData\Local\Temp\mihomo.zip`），
  并去掉脆弱的手工 `.replace(/\//g, '\\')` 反斜杠替换，交给 Node path 统一处理。
- 注意：本沙箱无 bun（脚本用 `import.meta.dir`，需 bun 运行），未能跑真实下载，仅验证了 temp 路径解析正确。
  建议用户在 Windows 上 `bun run download:cores` 跑一次确认端到端通过。
- 真正负责下载的是 `scripts/download-cores.ts`，`packages/proxy/src/CoreDownloader.ts` 的 `downloadMihomo` 只是抛错提示。
